# AniRate

Небольшое Rails-приложение «выбор аниме по картинке»: жанр → случайное аниме → оценка 1–5 → добавление в избранное.

## Возможности

- Регистрация и вход (Devise)
- Случайный выбор аниме по жанру
- Оценка 1–5 и сохранение в БД
- Избранное (toggle-звёздочка)
- Статистика по оценкам
- Локализация RU/EN

## Запуск

```bash
bundle install
rails db:create
rails db:migrate
rails db:seed
rails s
```
